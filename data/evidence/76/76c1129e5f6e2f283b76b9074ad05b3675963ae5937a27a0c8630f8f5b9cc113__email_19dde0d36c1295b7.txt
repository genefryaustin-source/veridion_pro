 🔧 Update: Apify MCP Configurator 
 [Image "MCP+configurator+%282%29.png"] 
 The Apify MCP Configurator has been redesigned to make it simpler to connect Apify to any LLM. Pick your Actors, choose your client, get a working config. No manual setup. Works with Claude, Cursor, and any MCP-compatible client. Try it at mcp.apify.com. 
 🎉 New integration: Dify
 [Image "apify+and+dify+%281%29.png"] 
 Dify just added Apify to its ecosystem. The integration is now live in the Dify Marketplace. It lets you run Actors, fetch dataset results, and trigger Dify workflows when a run finishes. Async and sync are both supported. Setup guide here. 
 ✉️ Verify emails in the same run you scrape them
 [Image "MCP+configurator.png"] 
 Stop paying twice. Once to scrape leads, once to clean them. The new email verification add-on validates every address in the same run across Google Maps, Google Search, and Contact Details Scraper. Campaign-ready lists, straight out of the box. 
 📄 Interactive API docs for standby Actors
 [Image "standby+%281%29.png"] 
 Standby Actors now have an Endpoints tab with interactive OpenAPI docs. Browse endpoints, inspect schemas, and run live API calls from the browser. Your token is attached automatically - no credential copy-pasting. 
 Available on Actor detail and Task pages in Console, and on Actor detail pages in Store. Full docs here. 
 🧩 New integration: Activepieces
 [Image "apify+and+dify.png"] 
 Activepieces is an open-source workflow automation platform, and Apify now has a native piece. Trigger a flow when an Actor run finishes, read dataset results, and pass scraped data straight to CRMs, dashboards, or notifications. No custom code needed. Set it up.
